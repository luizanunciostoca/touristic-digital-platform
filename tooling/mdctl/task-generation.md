Run from a clean current-main checkout: `node tooling/mdctl/task-generation.mjs ACTION WORKSPACE MAIN_SHA PR EXECUTOR [VALUE]`. `inspect` reads Git/GitHub and returns a request; save it outside the worktree. `prepare` takes REQUEST_JSON; commit its metadata, then `prove` takes NONCE. Unintegrated executables cannot run through the CLI.

`HISTORY` validates the executor's existing task/context/handoff/leases. Missing history blocks request creation and execution; this delivery does not implement MISSING recovery. Active leases, invalid history, closed PRs and identity drift block execution. Fresh tasks use `task start`. Existing history bytes remain unchanged. Restarted tasks may reuse older leases; proof must follow task start and precede submission.

Requests expire within 30 minutes and claim expiry. Prepare locks the common Git directory, records immutable intent and runs bounded real proofs before projecting LOCAL_PROVEN. PREPARED_REQUIRES_FINAL_PROOF is not acceptance. Prove validates journals, recaptures identity and tests the final commit; receipts bind main, candidate, tree, context and released leases. Local ADMISSION/CERTIFY, independent review and remote gates still apply; no preliminary proof becomes final proof.

Journals reside under the worktree Git state at `morro-control/generations/NONCE`. Nonces are single-use. Failure retains evidence/locks for reconciliation: never delete locks or extend requests blindly. Local locking does not fence other environments; provider/Git drift aborts without automatic rollback. CLI errors emit only GENERATION_COMMAND_FAILED. There is no CLI transport injection, bootstrap flag, merge, push, deploy, protection change or acceptance of remote proof.
