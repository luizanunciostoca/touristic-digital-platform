# Master Brand + Destination Brand System V2

This directory is the repository integration point for the governed V2 brand family.

## Authority

1. Live GitHub state and release governance.
2. Approved `CONCEPT_02_APPROVED` reference.
3. Master Brand + Destination Brand System V2 evidence package.
4. Historical V1 assets only as superseded source/provenance.

## Family

- Touristic Digital Platform — **REDE**.
- Morro Digital — **PERCURSO**.
- Itacaré Digital — **FLUXO**.

Shared DNA is expressed through round nodes, connected curves, 5px master route geometry, the coral human/value node, typography hierarchy and semantic separation between platform, destination and product colors.

Destination marks are intentionally not copies of the TDP sphere.

## Responsive assets

The committed SVG source contains independently drawn `symbol` and `micro` variants for all three brands. Micro artwork removes detail and increases route weight; it is not the master SVG scaled down.

The full governed asset package additionally contains horizontal, vertical and compact lockups, gradient/flat/black/white/grayscale variants, PNG/WebP exports, vector PDFs, favicons and the complete app-icon matrix. Those binary/derivative files remain release artifacts and Drive governance evidence rather than source-code dependencies in this initial ChangeSet.

## Governance

- `TERRITORIAL_DESIGN_VALIDATION = INTERNAL`.
- No community validation is claimed.
- Itacaré tagline selection is `NEEDS_HUMAN_VALIDATION`.
- Destination accent colors never replace semantic success/warning/error/info tokens.
- V1 master assets are retained as superseded history, not silently overwritten.
- Production publication is outside this ChangeSet.

## Runtime integration

This ChangeSet establishes source authority and tokens in `@touristic/design-system`. Product-runtime replacement of existing Morro PWA icons/theme assets is a separate bounded ChangeSet after the V2 family is accepted and exact-head visual regression evidence is available.
