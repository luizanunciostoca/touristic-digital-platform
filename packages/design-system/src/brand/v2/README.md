# Touristic Digital Platform — Brand Family V2

This directory is the source-code integration point for the governed Master Brand + Destination Brand System V2.

## Authority

1. GitHub current main and release governance.
2. Owner-approved Concept 02 reference.
3. Governed V2 evidence package in the institutional Drive.
4. Historical V1 assets only as provenance or superseded source.

## Family architecture

- Touristic Digital Platform — **REDE**.
- Morro Digital — **PERCURSO**.
- Itacaré Digital — **FLUXO**.

Shared DNA is expressed through circular nodes, connected curves, shared geometry, the coral human/value node and a common token hierarchy. Destination marks are intentionally distinct silhouettes and are not copies of the TDP network globe.

## Responsive artwork

Each brand has a full symbol and an independently simplified micro mark. Micro artwork removes connections and increases route weight rather than shrinking the full SVG indefinitely.

The complete governed package additionally contains horizontal, vertical and compact lockups, gradient/flat/black/white/grayscale variants, PNG/WebP exports, vector PDFs, favicons and app-icon matrices.

## Governance

- `TERRITORIAL_DESIGN_VALIDATION = INTERNAL`.

- Destination accents never replace semantic success/warning/error/info colors.

- Production publication is outside this ChangeSet.

## Product integration boundary

This ChangeSet establishes canonical V2 source geometry, token authority and machine-verifiable hashes in `@touristic/design-system`. Runtime replacement of public PWA assets and product-surface branding is intentionally separated into a bounded follow-up ChangeSet with visual-regression and accessibility proof.
